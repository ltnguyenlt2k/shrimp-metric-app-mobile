# Model xuất cho điện thoại

Tạo thư mục `android/` cho bản LiteRT và `ios/` cho bản Core ML khi model đã được huấn luyện. Mỗi bản xuất cần manifest ghi model, phiên bản dữ liệu, cấu hình tiền xử lý, thứ tự lớp, runtime, hash và kết quả kiểm thử thiết bị. Chọn bản phát hành rồi mới đưa vào app Flutter.
